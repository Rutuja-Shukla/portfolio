# Rutuja Shukla - Portfolio

A modern, responsive portfolio application for **Rutuja Shukla**, Senior Software Developer specializing in backend engineering, distributed systems, financial software at Barclays, and machine learning.

## Features

- **Home**: Dynamic introduction with bio and quick navigation.
- **Projects**: Interactive showcase featuring ML, NLP, time series, and geospatial projects with modal details and direct GitHub links.
- **About**: In-depth overview of technical skillsets (Languages, Backend, Frontend, Databases, AI/ML, Tools), career timeline at Barclays and Starling Solutions, and education history.
- **Connect / Contact**: Direct communication channels (Email, LinkedIn, GitHub) alongside an interactive contact message form with local storage persistence.
- **Theme Switcher**: Smooth light and dark mode toggling with preferences saved to `localStorage`.
- **Resume Download**: Quick-access button to view or download Rutuja's PDF resume directly or via Google Drive.
- **Glassmorphism Navigation**: Floating navigation bar with responsive layout for mobile and desktop screens.

## Tech Stack

- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 & custom glassmorphism styles
- **Icons**: Lucide Icons & SVG components
- **Routing**: React Router v7

## Getting Started

```bash
# Install dependencies
npm install

# Start local development server
npm run dev

# Build for production
npm run build
```
